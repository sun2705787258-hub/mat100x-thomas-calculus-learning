How To Use

使用说明

这是一个离线学习站。你可以从首页、全书结构或任意章节进入，不需要登录，也不需要联网。

第一次使用

  1. 先在“全书结构”确认 17 章主线。
  2. 进入章节，按“学习目标 → 概念 → 公式 → 例题 → 易错点”阅读。
  3. 完成章末练习，依次展开提示、关键步骤和完整解析。
  4. 用自测清单和错题记录检查薄弱点。

学习功能

  • 全站搜索支持中英文术语、公式名和题号。
  • 浏览器会保存自测勾选与错题记录。
  • 每章可下载独立 A4 PDF。
  • 批次历史页保留在归档区，不作为主学习路径。

离线与打印

KaTeX、字体、样式和脚本都随站点提供。直接打开 index.html 即可；打印时使用各章 PDF，避免浏览器分页差异。
